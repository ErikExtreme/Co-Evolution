## Usage Patterns

### Pattern 1: Complete Registration (Recommended)

```csharp
void OnWaveEnd(bool playerSurvived)
{
    float duration = Time.time - waveStartTime;
    
    foreach (var (genome, tracker) in ModuleManager.GetAllModules())
    {
        // Calculate all metrics
        float damageEff = CalculateDamageEfficiency(genome, tracker);
        float survival = tracker.survivalContribution;
        float synergy = CalculateOffensiveSynergy(genome);
        float powerEff = CalculatePowerEfficiency(genome);
        float roleAlign = CalculateRoleFulfillment(genome, tracker);
        
        // Register all at once
        BattleMetricsRecorder.Instance.RegisterModuleMetricsComplete(
            genome.id,
            damageEff, survival, synergy, powerEff, roleAlign,
            duration, playerSurvived
        );
    }
}
```

### Pattern 2: Incremental Registration (Simple)

```csharp
void OnDamageEvent(int moduleId, float damage) 
    => CombatEventRouter.Instance.ReportModuleDamageMitigated(moduleId, damage);

void OnWeaponFire(int moduleId, float synergyScore)
    => BattleMetricsRecorder.Instance.RegisterModuleOffensiveSynergy(moduleId, synergyScore);

void OnWaveEnd(bool survived)
    => ModuleManager.Instance.RegisterBattleMetricsForAll(duration, survived);
```

## Metric Dependencies

```
damageEfficiency
    ? Requires: Damage prevented, Defensive stat investment
    ?? Source: ShipHealth.TakeDamage()

survivalContribution
    ? Requires: Time alive, Total battle duration
    ?? Source: WaveManager/BattleController

offensiveSynergy
    ? Requires: Grid available, Weapons equipped, Weapon performance
    ?? Source: Weapon/WeaponController classes

powerEfficiency
    ? Requires: Power capacity/regen, Power consumed
    ?? Source: PowerManager/Energy system

roleFulfillment
    ? Requires: Genome mapping, Actual performance mapping
    ?? Source: Mapping.MapGenome(), gameplay simulation

battleDuration
    ? Requires: Battle start/end timestamps
    ?? Source: WaveManager

survivalSuccess
    ? Requires: Ship HP at end of battle
    ?? Source: PlayerHealth
```

## Performance Impact

- **Per-Module Registration:** O(1) - direct field assignment
- **Per-Batch (all modules):** O(n) where n = module count (typically < 10)
- **Fitness Calculation:** O(1) per module - same cost as before
- **JSON Serialization:** ~7% more data per module (7 new float fields)
- **Overall:** Negligible performance impact
